# Важно!
Для выполнения тестов из папки 10_lesson должны быть установлены все зависимости из файла _requirements.txt._
Для получения отчета о проведенном тестировании должны быть установлены _allure_ последней версии и _Java_ версии 8 и выше, а также добавлены переменные окружения PATH и JAVA_HOME.

# Работа с тестами:

1. Для запуска тестов используй команду **pytest --alluredir ./allure-results**
*(pytest проводит тестирование с использованием браузера Chrome, результаты тестирования сохраняются в папку allure-results)*

2. Для генерации отчета используй команду **allure generate ./results -o ./final-report**
*(allure сформирует отчет в папке final-report)*

3. Для просмотра результата отчета используй команду **allure open ./final-report** 
*(сформированный отчет открывается в браузере для просмотра)*

4. Для завершения процесса в терминале введи команду ctrl+C
